# PDF fonts

Latin subsets of the product fonts, embedded in exported PDFs because rendering runs
offline (every network request is aborted).

- `InstrumentSans-Latin.woff2`: Instrument Sans, variable weight 400–700.
- `JetBrainsMono-Latin.woff2`: JetBrains Mono, variable weight 100–800.

Both are licensed under the SIL Open Font License 1.1 (https://openfontlicense.org) and
match the files `next/font/google` self-hosts for the web app.
